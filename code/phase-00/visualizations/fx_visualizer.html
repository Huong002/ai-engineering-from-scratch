1. Đạo hàm số — sai phân trung tâm

Hai điểm lân cận x−h và x+h tạo thành một dây cung xấp xỉ tiếp tuyến tại x.

def numerical_derivate(f, x, h=1e-7):
    return (f(x + h) - f(x - h)) / (2 * h)
Thử với dữ liệu mẫuf(x)=x², x=2, h=0.1

2. Gradient nhiều biến — từng tọa độ một

Giữ yên tọa độ còn lại, dịch x một chút để đo ∂f/∂x; sau đó làm tương tự với y.

def numerical_gradient(f, point, h=1e-7):
    gradient = []
    for i in range(len(point)):
        point_plus = list(point)
        point_minus = list(point)
        point_plus[i] += h
        point_minus[i] -= h
        partial = (f(point_plus) - f(point_minus)) / (2 * h)
        gradient.append(partial)
    return gradient
Thử với dữ liệu mẫuf=x²+3xy+y², point=[1,2]

3. Gradient descent 1D — đi xuống cái bát

Với f(x)=x², gradient 2x luôn chỉ lên dốc; trừ learning rate × gradient sẽ đưa x về 0.

x = 5.0
lr = 0.1
for step in range(20):
    grad = 2 * x
    x = x - lr * grad
    print(step, x, x ** 2)
Mỗi lần cập nhật là một bước xuống dốcx bắt đầu = 5, lr = 0.1

4. Gradient descent 2D — điểm trượt về tâm

f(x,y)=x²+y² có các đường đồng mức tròn; gradient chỉ ra ngoài nên cập nhật đi về tâm.

point = [4.0, 3.0]
lr = 0.1
for step in range(30):
    grad = numerical_gradient(f_2d, point)
    point = [p - lr*g for p, g in zip(point, grad)]
    loss = f_2d(point)
Vector điểm thay đổi theo từng vònglr = 0.1

5. Kiểm tra sai phân trên nhiều hàm

Cùng một công thức sai phân trung tâm được thử trên năm hàm; so sánh với đạo hàm giải tích để xem sai số.

for name, f, df in test_functions:
    num = numerical_derivate(f, x)
    ana = df(x)
    err = abs(num - ana)
    print(name, num, ana, err)
Chọn một hàm để kiểm chứngx = 2

6. Hessian — độ cong theo hai hướng

Hessian gom đạo hàm bậc hai thành ma trận; dấu của đường chéo giúp nhận ra cái bát hay yên ngựa.

fxx = (f(x+h,y) - 2*f(x,y) + f(x-h,y)) / h**2
fyy = (f(x,y+h) - 2*f(x,y) + f(x,y-h)) / h**2
fxy = (f(x+h,y+h) - f(x+h,y-h)
       - f(x-h,y+h) + f(x-h,y-h)) / (4*h**2)
return [[fxx, fxy], [fxy, fyy]]
Đọc độ cong từ ma trậnh = 0.01, điểm (0,0)

7. Taylor — ghép các mảnh tiếp tuyến và độ cong

Bậc 0 lấy giá trị gốc; bậc 1 thêm độ dốc; bậc 2 thêm độ cong quanh x₀.

result = f(x0)
if order >= 1:
    result += f_prime(x0) * h
if order >= 2:
    result += 0.5 * f_double_prime(x0) * h ** 2
return result
Bật thêm từng số hạngsin(h), x₀=0, h=0.5

8. Hồi quy tuyến tính — học đường thẳng từ dữ liệu

Mỗi epoch đo sai số dự đoán, cộng gradient của w và b rồi cập nhật để đường gần các điểm hơn.

for x, y in zip(xs, ys):
    pred = w * x + b
    error = pred - y
    total_loss += error ** 2
    dw += 2 * error * x
    db += 2 * error
dw /= len(xs)
db /= len(xs)
w -= lr * dw
b -= lr * db
Nhìn đường học qua vài epoch đầuŷ=wx+b · lr=0.01 · khởi tạo w=b=0
