1. __mul__ — nhân hai số

Hai thừa số là chiều của hình chữ nhật; mỗi ô là một đơn vị trong tích.

Nếu out.grad=1 → a.grad += 3, b.grad += 2
def __mul__(self, other):
    other = other if isinstance(other, Value) else Value(other)
    out = Value(self.data * other.data, (self, other), '*')
    def _backward():
        self.grad += other.data * out.grad
        other.grad += self.data * out.grad
    out._backward = _backward
    return out
1 · Nhân xuôi2 hàng và 3 cột tạo 6 ô: 2×3=6.
2 · Nối đồ thịValue kết quả nhớ hai đầu vào.
3 · GradientĐạo hàm theo một thừa số bằng thừa số kia.

2. relu() — cổng lọc số âm

Đầu vào âm bị chặn về 0; đầu vào dương đi qua nguyên vẹn.

x<0: gradient × 0 · x>0: gradient × 1
def relu(self):
    out = Value(max(0, self.data), (self,), 'relu')
    def _backward():
        self.grad += (1.0 if out.data > 0 else 0.0) * out.grad
    out._backward = _backward
    return out
1 · x=−2Điểm bên trái 0; đầu ra thành 0.
2 · x=3Điểm bên phải 0; đầu ra giữ nguyên 3.
3 · BackwardNhánh phẳng chặn gradient; nhánh nghiêng cho gradient đi qua.

3. backward() — đi ngược trên đồ thị

Ví dụ p=x×y, L=p+x. Gradient về x có hai đường nên được cộng dồn.

Thứ tự xuôi: x,y,p,L · thứ tự ngược: L,p,y,x
def backward(self):
    topo = []
    vistied = set()
    def build_topo(v):
        if v not in vistied:
            vistied.add(v)
            for child in v._prev:
                build_topo(child)
            topo.append(v)
    build_topo(self)
    self.grad = 1.0
    for v in reversed(topo):
        v._backward()
1 · Xếp nútThăm các nút cha trước khi thêm nút hiện tại.
2 · Gieo gradientGradient của kết quả cuối được đặt bằng 1.
3 · Đi ngượcChạy backward ở từng nút; hai nhánh về x được cộng lại.
Trong code hiện tại, vòng lặp đang dùng v._prev nhưng __init__ lưu là prev. Cần đổi thành v.prev để backward chạy được.

4. Đổi dấu, trừ và toán tử đảo

Các hàm đặc biệt tái sử dụng cộng, nhân hoặc đổi dấu; trục số cho thấy kết quả thật.

__rsub__: 5−Value(2) → 5 + (−Value(2)) = Value(3)
def __neg__(self):
    return self * -1

def __sub__(self, other):
    return self + (-other)

def __radd__(self, other):
    return self + other

def __rmul__(self, other):
    return self * other

def __rsub__(self, other):
    return other + (-self)
1 · Đổi dấu−x là x nhân −1; số phản chiếu qua 0.
2 · Phép trừa−b được viết lại thành a+(−b).
3 · Thứ tự đảo__radd__/__rmul__ chuyển về phép thường; __rsub__ giữ đúng thứ tự bằng other+(−self).

5. Lũy thừa và phép chia

Lũy thừa là nhân lặp; chia trở thành nhân với nghịch đảo.

__truediv__: self * (other ** −1)
def __pow__(self, n):
    out = Value(self.data ** n, (self,), f'**{n}')
    def _backward():
        self.grad += n * (self.data ** (n - 1)) * out.grad
    out._backward = _backward
    return out

def __truediv__(self, other):
    return self * (other ** -1) if isinstance(other, Value) else self * (Value(other) ** -1)
1 · Tính xuôi2³ là ba thừa số 2, kết quả là 8.
2 · Đạo hàmHạ số mũ xuống: 3×2²=12.
3 · Chia6/2 thành 6×2⁻¹; nghịch đảo của 2 là 0.5.

6. exp(), log(), tanh()

Đồ thị cho thấy hình dạng hàm và độ dốc tạo nên gradient.

def exp(self):
    import math
    e = math.exp(self.data)
    out = Value(e, (self,), 'exp')
    def _backward(): self.grad += e * out.grad
    out._backward = _backward
    return out

def log(self):
    import math
    out = Value(math.log(self.data), (self,), 'log')
    def _backward(): self.grad += (1.0 / self.data) * out.grad
    out._backward = _backward
    return out
def tanh(self):
    import math
    t = math.tanh(self.data)
    out = Value(t, (self,), 'tanh')
    def _backward():
        self.grad += (1 - t ** 2) * out.grad
    out._backward = _backward
    return out
expỞ x=1, đầu ra và độ dốc đều ≈2.718.
logỞ x=e, đầu ra là 1; độ dốc 1/e≈0.368.
tanhỞ x=1, đầu ra ≈0.762; gradient co lại ≈0.420.

7. __init__ và __repr__

Một nút Value giữ dữ liệu cùng lịch sử tính toán; repr biến nút thành chuỗi dễ đọc.

def __init__(self, data, children=(), op=''):
    self.data = data
    self.grad = 0.0
    self._backward = lambda: None
    self.prev = set(children)
    self._op = op

def __repr__(self):
    return f"Value(data={self.data:.4f} , grad={self.grad:.4f})"
1 · Lưu giá trịdata là số; grad ban đầu bằng 0.
2 · Lưu đường điprev, op và _backward cho biết nút đến từ đâu và gradient đi thế nào.
3 · Hiển thịrepr định dạng hai số thành chuỗi bốn chữ số thập phân.
